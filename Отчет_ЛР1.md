### 3.2. Модель данных и иерархия классов

#### 3.2.1. Базовый класс Batch

Класс `Batch` представляет основную сущность предметной области — партию товара на складе:

```java
package ru.nstu.labs.core.model;

import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;
import java.util.Objects;

public class Batch implements Editable {
  protected String sku;           // Артикул (уникальный идентификатор)
  protected String name;          // Название товара
  protected int quantity;         // Количество единиц
  protected String cell;          // Номер ячейки на складе
  protected LocalDate deliveryDate; // Дата завоза

  public Batch(String sku, String name, int quantity, 
               String cell, LocalDate deliveryDate) {
    this.sku = sku;
    this.name = name;
    this.quantity = quantity;
    this.cell = cell;
    this.deliveryDate = deliveryDate;
  }

  // Геттеры и сеттеры опущены для краткости

  @Override
  public List<String> validate() {
    List<String> errors = new ArrayList<>();
    if (sku == null || sku.isBlank()) {
      errors.add("Артикул не может быть пустым");
    }
    if (name == null || name.isBlank()) {
      errors.add("Название не может быть пустым");
    }
    if (quantity < 0) {
      errors.add("Количество не может быть отрицательным");
    }
    if (cell == null || cell.isBlank()) {
      errors.add("Ячейка не может быть пустой");
    }
    if (deliveryDate == null) {
      errors.add("Дата завоза должна быть указана");
    }
    return errors;
  }

  @Override
  public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Batch batch)) return false;
    return Objects.equals(sku, batch.sku);
  }

  @Override
  public int hashCode() {
    return Objects.hash(sku);
  }
}
```

**Ключевые особенности реализации:**

1. **Модификаторы доступа `protected`:** поля объявлены как `protected`, что позволяет наследникам получать прямой доступ к данным
2. **Использование `LocalDate`:** для работы с датами применяется современный API `java.time`, а не устаревший `java.util.Date`
3. **Валидация через метод `validate()`:** вместо выброса исключений в конструкторе используется отложенная валидация с возвратом списка ошибок
4. **Идентификация по артикулу:** методы `equals()` и `hashCode()` используют только поле `sku`, что соответствует бизнес-логике (артикул — уникальный идентификатор)

#### 3.2.2. Класс ArchivedBatch (read-only)

Архивная партия представляет собой неизменяемый объект — реализацию паттерна "Immutable Object":

```java
package ru.nstu.labs.core.model;

import java.time.LocalDate;

public final class ArchivedBatch extends Batch {

  public ArchivedBatch(String sku, String name, int quantity, 
                       String cell, LocalDate deliveryDate) {
    super(sku, name, quantity, cell, deliveryDate);
  }

  @Override
  public void setSku(String sku) {
    throw new UnsupportedOperationException();
  }

  @Override
  public void setName(String name) {
    throw new UnsupportedOperationException();
  }

  @Override
  public void setQuantity(int quantity) {
    throw new UnsupportedOperationException();
  }

  @Override
  public void setCell(String cell) {
    throw new UnsupportedOperationException();
  }

  @Override
  public void setDeliveryDate(LocalDate deliveryDate) {
    throw new UnsupportedOperationException();
  }
}
```

**Технические решения:**

1. **Модификатор `final`:** класс помечен как `final`, что запрещает дальнейшее наследование и гарантирует неизменяемость на уровне типа
2. **Переопределение сеттеров:** все методы изменения состояния выбрасывают `UnsupportedOperationException`
3. **Отсутствие реализации `Editable`:** класс наследует интерфейс от родителя, но логика GUI проверяет тип через `instanceof`, блокируя редактирование

Этот подход реализует требование методички: **"Архивная партия (read-only)"**.

#### 3.2.3. Класс ImportedBatch

Импортная партия расширяет базовую модель дополнительными полями для учета международных поставок:

```java
package ru.nstu.labs.core.model;

import java.time.LocalDate;
import java.util.List;

public class ImportedBatch extends Batch {
  private String country;       // Страна происхождения
  private String customsCode;   // Таможенный код

  public ImportedBatch(String sku, String name, int quantity, 
                       String cell, LocalDate deliveryDate,
                       String country, String customsCode) {
    super(sku, name, quantity, cell, deliveryDate);
    this.country = country;
    this.customsCode = customsCode;
  }

  public String getCountry() {
    return country;
  }

  public void setCountry(String country) {
    this.country = country;
  }

  public String getCustomsCode() {
    return customsCode;
  }

  public void setCustomsCode(String customsCode) {
    this.customsCode = customsCode;
  }

  @Override
  public List<String> validate() {
    List<String> errors = super.validate();
    if (country == null || country.isBlank()) {
      errors.add("Страна не может быть пустой");
    }
    if (customsCode == null || customsCode.isBlank()) {
      errors.add("Таможенный код не может быть пустым");
    }
    return errors;
  }
}
```

**Принципы наследования:**

1. **Расширение валидации:** метод `validate()` сначала вызывает `super.validate()` для проверки базовых полей, затем добавляет проверки специфичных полей
2. **Дополнительные поля:** новые поля объявлены как `private`, инкапсуляция сохранена
3. **Совместимость с полиморфизмом:** объекты `ImportedBatch` могут обрабатываться как `Batch`, но при необходимости можно получить доступ к специфичным полям через приведение типа

### 3.4. Обработка ошибок CSV

#### 3.4.1. Перечисление CsvErrorCode

Типизированные коды ошибок обеспечивают структурированную обработку проблем при парсинге:

```java
package ru.nstu.labs.core.exception;

public enum CsvErrorCode {
  WRONG_FIELD_COUNT("Неверное количество колонок в строке"),
  BAD_NUMBER("Некорректный числовой формат количества"),
  INVALID_DATE("Некорректный формат даты (ожидается ГГГГ-ММ-ДД)"),
  UNKNOWN_TYPE("Неизвестный тип сущности партии"),
  VALIDATION_FAILED("Ошибка валидации значений полей"),
  EMPTY_FILE("CSV-файл пуст или не содержит данных");

  private final String description;

  CsvErrorCode(String description) {
    this.description = description;
  }

  public String getDescription() {
    return description;
  }
}
```

**Преимущества enum-подхода:**

1. **Типобезопасность:** невозможно передать несуществующий код ошибки
2. **Централизация:** все коды определены в одном месте
3. **Читаемость:** вместо магических чисел используются осмысленные константы
4. **Расширяемость:** легко добавить новые типы ошибок

#### 3.4.2. Класс CsvParseException

Пользовательское исключение хранит контекст ошибки для детальной диагностики:

```java
package ru.nstu.labs.core.exception;

public class CsvParseException extends Exception {
  private final int lineNumber;
  private final CsvErrorCode errorCode;
  private final String rawLine;

  public CsvParseException(int lineNumber, CsvErrorCode errorCode, 
                           String rawLine, String details) {
    super("Строка " + lineNumber + " [" + errorCode.name() + "]: " + details);
    this.lineNumber = lineNumber;
    this.errorCode = errorCode;
    this.rawLine = rawLine;
  }

  public int getLineNumber() { return lineNumber; }
  public CsvErrorCode getErrorCode() { return errorCode; }
  public String getRawLine() { return rawLine; }
}
```

**Структура исключения:**

1. **Номер строки:** позволяет пользователю найти проблему в исходном файле
2. **Код ошибки:** категория проблемы для программной обработки
3. **Исходная строка:** сохранение оригинального текста для анализа
4. **Детальное описание:** человекочитаемое сообщение об ошибке

Это реализует требование на уровень **"Максимум"**: *"собственные исключения загрузки с кодами ошибок"*.

### 3.5. Репозиторий для работы с CSV

Класс `CsvBatchRepository` инкапсулирует всю логику работы с файлами:

```java
package ru.nstu.labs.core.csv;

import java.io.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.LocalDate;
import java.time.format.DateTimeParseException;
import java.util.*;
import ru.nstu.labs.core.exception.*;
import ru.nstu.labs.core.model.*;

public class CsvBatchRepository {

  // Record для возврата результата загрузки
  public record LoadResult(List<Batch> items, 
                          List<CsvParseException> errors) {}

  private static final String HEADER =
      "TYPE;SKU;NAME;QUANTITY;CELL;DELIVERY_DATE;COUNTRY;CUSTOMS_CODE";

  public LoadResult load(Path file) throws IOException {
    List<Batch> items = new ArrayList<>();
    List<CsvParseException> errors = new ArrayList<>();

    try (BufferedReader reader = 
         Files.newBufferedReader(file, StandardCharsets.UTF_8)) {
      String line = reader.readLine();
      if (line == null) {
        errors.add(new CsvParseException(0, CsvErrorCode.EMPTY_FILE, 
                                        "", "Файл пуст"));
        return new LoadResult(items, errors);
      }

      int lineNumber = 1;
      while ((line = reader.readLine()) != null) {
        lineNumber++;
        if (line.isBlank()) {
          continue;
        }

        try {
          Batch parsed = parseLine(line, lineNumber);
          items.add(parsed);
        } catch (CsvParseException ex) {
          errors.add(ex);  // Битые строки пропускаются
        }
      }
    }
    return new LoadResult(items, errors);
  }

  private Batch parseLine(String line, int lineNumber) 
      throws CsvParseException {
    String[] parts = line.split(";", -1);
    if (parts.length < 8) {
      throw new CsvParseException(
          lineNumber, CsvErrorCode.WRONG_FIELD_COUNT, line,
          "Ожидалось 8 колонок, получено: " + parts.length);
    }

    String type = parts[0].trim();
    String sku = parts[1].trim();
    String name = parts[2].trim();
    String quantityStr = parts[3].trim();
    String cell = parts[4].trim();
    String dateStr = parts[5].trim();
    String country = parts[6].trim();
    String customsCode = parts[7].trim();

    int quantity;
    try {
      quantity = Integer.parseInt(quantityStr);
    } catch (NumberFormatException e) {
      throw new CsvParseException(
          lineNumber, CsvErrorCode.BAD_NUMBER, line,
          "Число '" + quantityStr + "' некорректно");
    }

    LocalDate date;
    try {
      date = LocalDate.parse(dateStr);
    } catch (DateTimeParseException e) {
      throw new CsvParseException(
          lineNumber, CsvErrorCode.INVALID_DATE, line,
          "Дата '" + dateStr + "' не соответствует формату YYYY-MM-DD");
    }

    Batch result = switch (type) {
      case "BATCH" -> new Batch(sku, name, quantity, cell, date);
      case "ARCHIVED" -> new ArchivedBatch(sku, name, quantity, cell, date);
      case "IMPORTED" -> new ImportedBatch(sku, name, quantity, cell, date, 
                                           country, customsCode);
      default -> throw new CsvParseException(
          lineNumber, CsvErrorCode.UNKNOWN_TYPE, line,
          "Тип '" + type + "' не поддерживается");
    };

    List<String> validationErrors = result.validate();
    if (!validationErrors.isEmpty()) {
      throw new CsvParseException(
          lineNumber, CsvErrorCode.VALIDATION_FAILED, line,
          String.join(", ", validationErrors));
    }

    return result;
  }

  public void save(Path file, List<Batch> items) throws IOException {
    try (BufferedWriter writer = 
         Files.newBufferedWriter(file, StandardCharsets.UTF_8)) {
      writer.write(HEADER);
      writer.newLine();

      for (Batch batch : items) {
        writer.write(toCsvLine(batch));
        writer.newLine();
      }
    }
  }

  private String toCsvLine(Batch batch) {
    if (batch instanceof ArchivedBatch) {
      return String.join(";", "ARCHIVED", batch.getSku(), 
                        batch.getName(),
                        String.valueOf(batch.getQuantity()),
                        batch.getCell(),
                        batch.getDeliveryDate().toString(), "", "");
    }

    if (batch instanceof ImportedBatch imported) {
      return String.join(";", "IMPORTED", imported.getSku(),
                        imported.getName(),
                        String.valueOf(imported.getQuantity()),
                        imported.getCell(),
                        imported.getDeliveryDate().toString(),
                        imported.getCountry(),
                        imported.getCustomsCode());
    }

    return String.join(";", "BATCH", batch.getSku(), batch.getName(),
                      String.valueOf(batch.getQuantity()),
                      batch.getCell(),
                      batch.getDeliveryDate().toString(), "", "");
  }
}
```

**Ключевые аспекты реализации:**

1. **Try-with-resources:** автоматическое закрытие файловых потоков
2. **UTF-8:** явное указание кодировки для корректной работы с кириллицей
3. **`split(";", -1)`:** сохранение пустых полей в конце строки
4. **Pattern Matching (switch):** использование современного синтаксиса Java 21 для создания объектов разных типов
5. **Record `LoadResult`:** компактный способ возврата двух списков из метода
6. **Полиморфизм при сохранении:** метод `toCsvLine()` проверяет реальный тип через `instanceof` и формирует соответствующую строку

private void showErrorSummaryDialog(List<CsvParseException> errors) {
  Alert alert = new Alert(Alert.AlertType.WARNING);
  alert.setTitle("Предупреждение при загрузке");
  alert.setHeaderText("Некоторые строки были пропущены (" + 
                     errors.size() + " шт.)");

  StringBuilder sb = new StringBuilder();
  for (CsvParseException ex : errors) {
    sb.append(ex.getMessage())
      .append("\n Исходная строка: ")
      .append(ex.getRawLine())
      .append("\n\n");
  }

  TextArea textArea = new TextArea(sb.toString());
  textArea.setEditable(false);
  textArea.setWrapText(true);

  alert.getDialogPane().setExpandableContent(textArea);
  alert.getDialogPane().setExpanded(true);
  alert.showAndWait();
}

Класс `BatchEditDialog` обеспечивает создание и редактирование партий:

```java
public class BatchEditDialog extends Dialog<Batch> {
  private final TextField skuField = new TextField();
  private final TextField nameField = new TextField();
  private final TextField quantityField = new TextField();
  private final TextField cellField = new TextField();
  private final DatePicker datePicker = new DatePicker(LocalDate.now());
  private final ComboBox<String> typeBox = new ComboBox<>();
  private final TextField countryField = new TextField();
  private final TextField customsCodeField = new TextField();

  public BatchEditDialog(Batch existing) {
    setTitle(existing == null ? "Добавление партии" : 
                                "Редактирование партии");

    typeBox.getItems().addAll("Базовая партия", "Импортная партия");
    typeBox.setValue("Базовая партия");

    // Динамическое управление полями
    countryField.setDisable(true);
    customsCodeField.setDisable(true);

    typeBox.setOnAction(e -> {
      boolean isImported = "Импортная партия".equals(typeBox.getValue());
      countryField.setDisable(!isImported);
      customsCodeField.setDisable(!isImported);
    });

    // Предзаполнение при редактировании
    if (existing != null) {
      typeBox.setDisable(true);  // Запрет смены типа
      skuField.setText(existing.getSku());
      skuField.setDisable(true);  // Артикул неизменен (ключ)
      nameField.setText(existing.getName());
      quantityField.setText(String.valueOf(existing.getQuantity()));
      cellField.setText(existing.getCell());
      datePicker.setValue(existing.getDeliveryDate());

      if (existing instanceof ImportedBatch imported) {
        typeBox.setValue("Импортная партия");
        countryField.setDisable(false);
        customsCodeField.setDisable(false);
        countryField.setText(imported.getCountry());
        customsCodeField.setText(imported.getCustomsCode());
      }
    }

    // Преобразование результата
    setResultConverter(dialogButton -> {
      if (dialogButton == saveButtonType) {
        int qty = 0;
        try {
          qty = Integer.parseInt(quantityField.getText().trim());
        } catch (NumberFormatException ignored) {}

        Batch batch;
        if ("Импортная партия".equals(typeBox.getValue())) {
          batch = new ImportedBatch(
              skuField.getText().trim(),
              nameField.getText().trim(), qty,
              cellField.getText().trim(),
              datePicker.getValue(),
              countryField.getText().trim(),
              customsCodeField.getText().trim());
        } else {
          batch = new Batch(
              skuField.getText().trim(),
              nameField.getText().trim(), qty,
              cellField.getText().trim(),
              datePicker.getValue());
        }

        List<String> errors = batch.validate();
        if (!errors.isEmpty()) {
          return null;  // Блокировка сохранения при ошибках
        }
        return batch;
      }
      return null;
    });
  }
}
```

**Особенности реализации:**

1. **Динамическая форма:** поля страны и таможенного кода активируются только для импортных партий
2. **Блокировка ключевых полей:** при редактировании нельзя изменить артикул и тип
3. **Валидация перед закрытием:** диалог не закрывается при некорректных данных
4. **Pattern Matching при предзаполнении:** `instanceof` с автоматическим приведением типа
